An Oxtail’s Journey

Humanities Capstone: Food Narratives · November 2026

An interactive 3D globe that follows oxtail from the farm to your fork, built for my undergraduate humanities capstone, Food Narratives, with Professor Risa Gorelick.

  • Night-lights globe with amber country highlights, pulsing city rings and animated migration arcs.
  • Ten cited stops, from the kill floor’s “fifth quarter” to the Caribbean diaspora and the price story.
  • Info card with Prev/Next and keyboard navigation, plus a phone bottom-sheet layout.

Tech: JavaScript, Vite, globe.gl, GSAP, TopoJSON

Content AI

Automated Gameplay Highlight Engine · December 2025 to March 2026

An intelligent pipeline that detects high-energy moments in gameplay footage using audio-first signal processing.

  • Audio-first detection using Librosa (HPSS + RMS) to isolate key events.
  • Production-grade FFmpeg rendering with smart merging and VFR safety.
  • Resumable batch processing queue with crash recovery (SQLite).
  • This project has taken a specialized route involving Docker and an MCP server. It’s currently in development; the code isn’t published yet, but the results look very promising!

Tech: Python, FFmpeg, Librosa, SQLite, Pydantic
